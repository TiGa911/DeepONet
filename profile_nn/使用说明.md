# ProfileNet 使用说明书

## —— EAST 等离子体剖面拟合的神经网络替代方案

---

## 一、系统概述

### 1.1 解决的问题

EAST 托卡马克的 ONETWO 输运计算需要将离散的诊断测量点（汤姆逊散射 TS、反射计 Refl、X 射线晶体谱仪 TXCS）转换为 201 点的平滑径向剖面。现有方法使用 `fitting_mtanh.py` 中的 **mtanh + spline 参数化拟合**（约 800 行手工调参物理代码），包含 L/H 模分支、最小二乘台基优化、Savitzky-Golay 滤波等复杂逻辑。

**ProfileNet** 将此步骤替换为一个小型神经网络（~50K 参数），学习 "离散散点 → 平滑剖面" 的映射关系，训练标签由现有 mtanh 拟合器自动生成。推理耗时 < 1ms（vs 原有 ~0.5s），且无需手工调参。

### 1.2 文件结构

```
fit/
├── profile_nn/                  # 神经网络剖面拟合包
│   ├── __init__.py              # 包入口，导出接口
│   ├── model.py                 # 模型架构 + 物理约束损失
│   ├── dataset.py               # 变长数据加载与批处理
│   ├── generate_data.py         # 训练数据生成（MDSplus 或合成数据）
│   ├── train.py                 # 训练脚本（含早停、学习率调度）
│   └── infer.py                 # 推理接口（nn_fit_te / ne / ti）
├── profile_nn_data/             # 训练数据目录（.npz 文件）
├── profile_nn_models/           # 训练好的模型（.pt 文件）
└── onetwo_output_nn.py          # NN 版本的 ONETWO 流程脚本
```

## 二、网络架构

### 2.1 总体设计：DeepONet 风格

系统采用 **DeepONet（深度算子网络）** 架构，天然适合"函数 → 函数"的映射任务。核心思想是将网络分为两个子网络，最后通过点积融合：

```
输入：{(ρ₁, y₁), (ρ₂, y₂), ..., (ρₙ, yₙ)}  ← 来自诊断的 N 个离散散点（N 不固定）
                              │
                ┌─────────────┴─────────────┐
                │                           │
          ┌─────▼──────┐            ┌───────▼──────┐
          │  Branch Net │            │   Trunk Net  │
          │ (SetEncoder)│            │(CoordDecoder)│
          │             │            │              │
          │ 每个散点    │            │ 每个输出坐标 │
          │ (ρ, y) → MLP│            │ ρⱼ → MLP     │
          │ → 全局最大池│            │ → b(ρⱼ)      │
          │ → 隐向量 z  │            │   基函数      │
          └──────┬──────┘            └───────┬──────┘
                 │                           │
                 │     z · b(ρⱼ) = yⱼ       │
                 └───────────┬───────────────┘
                             │
                    ┌────────▼────────┐
                    │   Softplus      │  ← 保证输出 > 0
                    └────────┬────────┘
                             │
        输出：{y(ρ₁), y(ρ₂), ..., y(ρ₂₀₁)}  ← 均匀 rho 网格上 201 点平滑剖面
```

### 2.2 核心模块详解

#### SetEncoder（分支网络）

```
MLP(2 → 64 → 128 → 128)，每层 ReLU 激活
→ 全局最大池化（Max Pooling over points）
→ 输出固定长度隐向量 z ∈ R¹²⁸
```

- **设计要点**：借鉴 PointNet 的置换不变性思想。每个 (ρ, y) 点独立通过共享 MLP，再由全局最大池化聚合成定长向量。这使得网络可以处理**任意数量**的诊断输入点（TS 约 20-25 点，Refl 约 15-20 点，TXCS 仅 3-15 点）。
- **变长处理**：训练时将每个 batch 内样本 padding 到相同长度，配合 boolean mask 使池化忽略填充位置。

#### CoordDecoder（主干网络）

```
MLP(1 → 128 → 128)，SiLU 激活
输入：标量坐标 ρⱼ ∈ [0, 1]
输出：基函数向量 b(ρⱼ) ∈ R¹²⁸
```

- **设计要点**：SiLU（Sigmoid Linear Unit）作为激活函数，其平滑性优于 ReLU，能产生更光滑的基函数。坐标作为输入保证了输出剖面在 ρ 空间中的**平滑性与连续性**。

#### 输出 = z · b(ρ)（点积融合）

这是 DeepONet 理论的核心——分支网络的隐向量 z 编码了"输入散点的整体形状"，主干网络的基函数 b(ρ) 提供了"在坐标 ρ 处的展开基底"，两者点积即为最终预测值。最后经 Softplus（光滑版 ReLU）保证输出为正。

### 2.3 Ti 网络的特化设计

Ti（离子温度）网络 `ProfileNet_Ti` 具有**双编码器结构**：

```
TXCS 散点 ──→ SetEncoder ──→ z_txcs ──┐
                                        ├──→ Fusion MLP ──→ z ──→ 输出
Te 台基数据 ──→ SetEncoder ──→ z_ped  ──┘   (256→128→128)
 (ρ≥0.88)
```

**设计理由**：TXCS 的 Ti 测量点通常非常稀疏（仅 3-15 个有效通道），尤其在台基区域几乎没有数据。原始物理拟合利用 Te 台基（ρ ≥ 0.88 的 Te 剖面）作为 Ti 外推的边界条件。网络通过独立编码 Te 台基数据，再经 Fusion MLP 与 TXCS 特征融合，复现了这一物理依赖。

### 2.4 物理约束损失函数

训练使用的损失函数是四项的加权和：

```
L = L_MSE + λ₁·L_mono + λ₂·L_bdy + λ₃·L_smooth
```

| 损失项 | 公式 | 权重 | 物理意义 |
|--------|------|------|---------|
| L_MSE | ‖y_pred − y_true‖² | 1.0 | 数据保真度，拟合训练标签 |
| L_mono | mean(ReLU(dy/dρ)) | 0.1 | 惩罚"上翘段"，强制单调递减 |
| L_bdy | mean((dy/dρ)²) for ρ<0.05 | 0.5 | 磁轴处导数≈0（轴对称对称性） |
| L_smooth | mean(|d²y/dρ²|) | 0.05 | 惩罚二阶导大值，防止锯齿振荡 |

**关键细节**：
- L_mono 使用 `ReLU` 而非绝对值——**只惩罚正值导数（递增段），不惩罚正常的递减**。
- L_bdy 仅在 ρ < 0.05 区域计算，对应托卡马克磁轴附近的物理对称条件。
- Softplus 输出层保证了正定性（硬约束），无需额外损失项。

## 三、使用流程

### 3.0 前置条件

```bash
# 确保安装依赖
pip install numpy scipy matplotlib torch MDSplus
```

### 3.1 第一步：生成训练数据

#### 情况 A：有 EAST MDSplus 连接（生产环境）

```bash
cd C:\Users\thunderobot\Desktop\py代码\fit

# 单炮号（测试用）
python -m profile_nn.generate_data --shots 81481 --output ./profile_nn_data

# 多炮号（建议至少 5-10 炮，覆盖不同放电参数区间）
python -m profile_nn.generate_data --shots 81481 81482 81483 81484 81485 --output ./profile_nn_data

# 每炮只取前 50 个时间片（快速测试）
python -m profile_nn.generate_data --shots 81481 --time-limit 50 --output ./profile_nn_data
```

**工作原理**：脚本连接 EAST MDSplus → 读取 TS/Refl/TXCS 原始数据 → 运行现有 mtanh 拟合器 → 保存 (散点输入, 拟合剖面) 对为 `.npz` 文件。

每个 `.npz` 文件包含：

| 字段 | 说明 |
|------|------|
| X_rho | 诊断测量点的 ρ 坐标（变长） |
| X_val | 诊断测量点的物理量值 |
| Y | mtanh 拟合后的 201 点剖面（训练标签） |
| X_te_ped_rho / X_te_ped_val | Te 台基数据（仅 Ti 样本） |
| shot, time, datatype | 元数据 |

#### 情况 B：无 MDSplus（离线测试）

```bash
# 生成合成数据用于开发测试
python -m profile_nn.generate_data --synthetic 500 --output ./profile_nn_data
```

生成 500 个/类型的参数化 mtanh 样剖面 + 模拟噪声散点，可完整跑通后续流程。

### 3.2 第二步：训练模型

```bash
# 训练全部三个诊断模型
python -m profile_nn.train --data ./profile_nn_data --datatype all --epochs 500 --output ./profile_nn_models

# 或单独训练
python -m profile_nn.train --data ./profile_nn_data --datatype Te --epochs 500
```

输出文件：
```
profile_nn_models/
├── ProfileNet_Te.pt      # ~58K 参数
├── ProfileNet_ne.pt      # ~58K 参数
└── ProfileNet_Ti.pt      # ~133K 参数（含双编码器）
```

**训练配置（全部可调）**：

| 参数 | 默认值 | 作用 |
|------|--------|------|
| `--epochs` | 500 | 训练轮数 |
| `--batch-size` | 64 | 批大小（内存不足时减小） |
| `--lr` | 1e-3 | 初始学习率（配合余弦退火） |
| `--w-mono` | 0.1 | 单调性惩罚权重 |
| `--w-bdy` | 0.5 | 磁轴边界条件权重 |
| `--w-smooth` | 0.05 | 二阶光滑性权重 |
| `--device` | cpu | `cpu` / `cuda` / `mps` |

训练过程会自动：
- 划分训练集/验证集/测试集（70%/15%/15%，按文件哈希随机）
- 使用 AdamW 优化器 + CosineAnnealingLR 学习率调度
- 验证集早停（patience=50），保存最佳模型

### 3.3 第三步：在 ONETWO 流程中使用

```bash
python onetwo_output_nn.py
```

程序会提示输入炮号，后续流程与原始 `onetwo_output.py` 完全相同：

```
输入炮号 → readmds() 读取诊断数据
         → nn_fit_te / ne / ti 替代 mtanh 拟合       ← 唯一的替换点
         → lower_onetwo() LHW 输运计算
         → 读取 gfile
         → 调用 onetwo_129_201 输运求解
```

输出结构：

```
results/
└── {shot}/
    └── {time}/
        ├── Te_shot{shot}_time{time}_nn.png    ← NN 拟合图（标注 NN）
        ├── ne_shot{shot}_time{time}_nn.png
        ├── Ti_shot{shot}_time{time}_nn.png
        └── onetwo_nn/                         ← ONETWO 运行结果
            ├── inone
            ├── g0_input
            └── LHCD_data_*.txt
```

> 注意：NN 版本输出到 `onetwo_nn/` 子目录（而非原始版本的 `onetwo/`），便于对比。

## 四、直接使用 API（无需完整 ONETWO 流程）

如果只想用神经网络替代剖面拟合部分，可以直接调用推理接口：

```python
import numpy as np
from profile_nn.infer import nn_fit_te, nn_fit_ne, nn_fit_ti, set_model_dir

# 指定模型目录
set_model_dir('./profile_nn_models')

# ===== Te 拟合 =====
rho_ts = np.array([0.1, 0.2, 0.35, 0.5, 0.7, 0.85, 0.92, 0.98])  # TS 测量点
te_eV  = np.array([3500, 3400, 3100, 2800, 2100, 1500, 800, 300]) # 原始 eV
rho_201, te_keV = nn_fit_te(rho_ts, te_eV)
# rho_201: (201,) 均匀网格
# te_keV:  (201,) Te 剖面 [keV]

# ===== ne 拟合 =====
rho_refl = np.array([0.05, 0.2, 0.4, 0.6, 0.8, 0.9, 0.95])
ne_1e19  = np.array([5.2, 5.0, 4.6, 4.0, 3.2, 2.5, 1.8])
rho_201, ne_201 = nn_fit_ne(rho_refl, ne_1e19)
# ne_201: (201,) 密度剖面 [1e19 m⁻³]

# ===== Ti 拟合（需要 Te 台基数据）=====
rho_txcs = np.array([0.15, 0.3, 0.5, 0.7, 0.85])   # TXCS 测量点
ti_keV   = np.array([2.1, 2.0, 1.8, 1.4, 0.9])      # Ti 值 [keV]
# Te 台基（ρ ≥ 0.88 区域的 Te 剖面值）
te_ped_x = np.array([0.88, 0.92, 0.96, 0.98])
te_ped_y = np.array([1.2, 0.8, 0.4, 0.2])
rho_201, ti_201 = nn_fit_ti(rho_txcs, ti_keV, te_ped_x, te_ped_y)
# ti_201: (201,) Ti 剖面 [keV]，已强制单调递减
```

## 五、单位约定速查

| 物理量 | 推理函数 | 输入单位 | 输出单位 | 备注 |
|--------|---------|---------|---------|------|
| Te | `nn_fit_te` | **eV**（MDSplus 原始值） | **keV** | 输入会被内部除以 1000 |
| ne | `nn_fit_ne` | **10¹⁹ m⁻³** | **10¹⁹ m⁻³** | 无转换 |
| Ti | `nn_fit_ti` | **keV** | **keV** | Te 台基输入也是 keV |

| ONETWO Namelist 写入 | 单位 | 转换 |
|---------------------|------|------|
| TEIN（电子温度） | **eV** | NN 输出 keV × 1000 |
| ENEIN（电子密度） | **cm⁻³** | NN 输出 10¹⁹ m⁻³ × 10¹³ |
| TIIN（离子温度） | **keV** | 直接写入，无需转换 |

> **注意**：原始 `onetwo_output.py` 的 TEIN 以 keV 写入（疑似 bug），`onetwo_output_nn.py` 已修正为 eV。

## 六、参数调优指南

### 6.1 什么时候需要调优

| 现象 | 调什么 | 方向 |
|------|--------|------|
| 芯部拟合差（ρ < 0.3 误差大） | `--epochs` | 增加到 1000 |
| 输出曲线有上翘段（非单调） | `--w-mono` | 从 0.1 → 0.5 甚至 1.0 |
| ρ = 0 附近导数明显不为零 | `--w-bdy` | 从 0.5 → 1.0 |
| 输出有锯齿状高频振荡 | `--w-smooth` | 从 0.05 → 0.2 |
| 台基区域偏差大 | 增加训练数据中 H 模样本比例 | 多跑几炮 H 模放电 |
| 内存不足 | `--batch-size` | 降至 16 或 8 |

## 七、常见问题

**Q: 需要 GPU 吗？**  
A: 不需要。模型仅 ~50K 参数，CPU 训练 500 epochs 约 5-10 分钟。

**Q: 训练数据需要多少？**  
A: 每类至少 500 样本起步，2000+ 可获得稳定结果。一炮 EAST 数据通常可产生 20-100 个有效时间片（取决于 TS 时间分辨率）。

**Q: 可以只训练部分诊断吗？**  
A: 可以。`--datatype Te` 只训练 Te，不影响 ONETWO 流程（但 Ti 依赖 Te，如果只训练 Ti 需要先有 Te 模型）。

**Q: NN 输出的剖面会违反物理吗？**  
A: Softplus 输出层保证正定性；单调性损失在训练时已正则化；Ti 推理后会额外施加 PCHIP 单调性后处理作为安全网。

**Q: 如何对比 NN 和原始 mtanh 的效果？**  
A: 跑同一炮号分别用 `onetwo_output.py`（原始）和 `onetwo_output_nn.py`（NN），比较 `results/{shot}/{time}/` 下的拟合图（NN 版有 `_nn` 后缀）及 ONETWO 输出文件。
